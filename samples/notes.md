# 现场记录

东一句西一句记下来的，回头看能少走点弯路。

- 老写法是直接乘的，几千行的矩阵一直没出过事。这次喂进去的是几十万行、上亿非零元素的一份数据，
  一按下去内存就一路往上抬，任务管理器里的曲线几乎竖着走，机器开始换页，最后进程被系统干掉。
  同事说那套写法把中间的东西整块摊开存了，输入越大越离谱。
- 客户内网机器装不了东西：没有外网，pip 连镜像源都拉不动，第三方库这条路直接封死。
  现场只能用 Python 自带的标准库写，页面也只能用浏览器原生那几样东西。
- 那边几个人要一起看结果，希望点开页面就能看出哪片区域有非零、一共多少个非零、这次跑了多久，
  方便对着屏幕一眼比对。
- 交付前对方特意强调过一次：同样的输入跑两遍，出来的东西必须一模一样，连顺序都不能变。
